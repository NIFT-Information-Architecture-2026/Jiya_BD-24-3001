# Math Arcade & Puzzle Quiz: Information Architecture Case Study

## 📌 Executive Project Summary
- **Institution:** NIFT Hyderabad — Fashion Communication / Information Architecture
- **Product Title:** Mobile Math Arcade & Puzzle Game (Ages 5–20)
- **Role:** Creative Director & Product Lead
- **Technical Architecture:** Interactive HTML5/CSS3/JS Web Prototype, Socratic AI Hint Engine, Diegetic World Map Navigation, COPPA-Compliant Parents Gate.

---

## 🗺️ Project Progression Through the 6 Stage-Gate Phases

### Phase 1: Narrative & Objectives (`UX_RESEARCH.md`)
- Established core problem space, target demographic tiers (Junior 5–8, Intermediate 9–13, Pro Arcade 14–20), and benchmark precedent analysis.

### Phase 2: Empathy & Demographic Psychology (`DEMOGRAPHIC_PSYCHOLOGY.md`)
- Mapped cognitive development milestones (Piaget operational stages), finger tap ergonomics (min 56px touch targets for 5–7 y/o down to 36px for teens), attention spans (3m–30m), and dual-user personas (Child Player vs. Adult Supervisor).

### Phase 3: Information Architecture & Taxonomy (`SITEMAP.md` & `IA_RESEARCH_DEEPDIVE.md`)
- Compared **Diegetic World Map** navigation against generic tabbed dashboards.
- Validated category labels through Tree Testing (`Daily Chest` 96% success, `Math Duel` 92% success).
- Enforced the **Max 2-Tap Rule** (no primary screen is > 2 taps away from the main hub).

### Phase 4: User Flows & Screen Sequence (`IA_SPEC.md`)
- Standardized the 6-stage core screen sequence:
  `Choose Age ──> Adventure Map ──> Challenges (Quiz) ──> Answer/Feedback (AI Explanation) ──> Results ──> Rewards`

### Phase 5: AI & Pedagogical Tutoring System (`AI_PEDAGOGY.md`)
- Designed 3-tier **Socratic AI Hint Generation** (Nudge, Scaffold, Guided Step).
- Created instant post-error step-by-step math explanations ($24 \div 6 = 4$ because $6 \times 4 = 24$).
- Formulated the Spaced Repetition Dynamic Difficulty Adjustment (DDA) algorithm.

### Phase 6: Interactive Prototyping & Deployment (`index.html`)
- Built and deployed a fully interactive, mobile-responsive web prototype demonstrating all screen flows, AI hint drawers, quiz challenges, rewards, and parent gate PIN modal.
